### 수정 시 주의

- **복사 스크립트와 `<div id="toast">`를 지우면 복사 버튼이 동작하지 않습니다.** 각 HTML 하단의 `copyPrompt()` 스크립트는 그대로 두세요.
- 차시를 추가하면 **모든 페이지의 상단 내비**와 `index.html` 카드를 함께 고쳐야 합니다(빠뜨리기 쉬움).
- 섹션을 추가할 때는 카드 `id`와 내비 `href="#id"`를 반드시 일치시키세요.
- 색은 각 HTML 맨 위 `:root` CSS 변수에서만 바꿉니다(`--brand:#5b8fd6`).

## 기능

- **외부 CDN·라이브러리 없는 단일 HTML** — 인터넷 없이 더블클릭만으로 열립니다
- **복사 버튼** — `navigator.clipboard` + `execCommand` 폴백. `file://`로 열어도 복사됩니다
- **화면 배율 조절** — 우측 하단 `+ / −` 버튼 또는 `+` `-` `0` 키. 강의장 좌석 거리에 맞춰 조절하며, 선택은 브라우저에 기억됩니다
- **sticky 내비** — 차시 이동 + 현재 페이지 섹션 바로가기
